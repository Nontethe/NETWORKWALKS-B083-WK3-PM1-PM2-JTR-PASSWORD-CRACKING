## 📌 Project Overview

This project covers **password cracking and password security** practicals completed during Week 3 of my cybersecurity internship.

Two modules were completed:

* **Module 1:** Password Cracking using John the Ripper (JTR) and Johnny.

The exercises were performed in an authorized educational environment using a password-protected PDF provided for the practical.

## 🔐 Module 1 – John the Ripper

I used **John the Ripper and Johnny** to recover the password of an authorized password-protected PDF.

The process involved:

1. Configuring Johnny with John the Ripper.
2. Extracting the PDF hash.
3. Saving the hash in a text file.
4. Loading the hash into Johnny.
5. Starting the password-recovery process.
6. Using the recovered password to open the PDF.

---

## 🌐 Module 2 – Networkwalks Tools

I used the **Networkwalks Hash Calculator** to extract the PDF hash and the **Networkwalks Password Cracker** to perform password recovery.

The recovered password was then used to verify access to the protected PDF.

## 📊 Key Findings

| Finding                                                   | Impact      |

| Weak passwords can be recovered through automated attacks | 🔴 High     |

## 🔐 Security Recommendations

* Use long, unique passwords.
* Avoid common or predictable passwords.
* Never reuse passwords across important accounts.
* Protect password hashes.
* Enable Multi-Factor Authentication (MFA).
* Use password managers where appropriate.
* Perform password-security testing only in authorized environments.
